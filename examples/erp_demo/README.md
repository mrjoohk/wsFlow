# ERP 모형 패키지

이 폴더는 실제 ERP·업무 계정에 연결하지 않는 읽기 전용 확장 예제다. 모듈 관리에서 이 폴더를 선택하고 신뢰 확인 후 미리보기 → 변경 예약 → 서버 재실행 순서로 추가한다. 초기 설정은 `{ "company": "예제 회사" }`를 사용할 수 있다.

새 실행의 ERP 모형 메뉴에서 화면과 API 등록을 확인한다. 설치 검사/예약 중에는 backend.py를 실행하지 않는다. 다음 기동에서 선택한 확장 코드는 앱의 권한으로 실행된다.

제거는 코드의 등록을 해제하며 데이터와 보관된 버전을 삭제하지 않는다. 이 예제는 업무 데이터를 만들지 않는다. 실제 ERP 연결, 자격·권한, 조회/쓰기, 오류·복구는 별도 모듈 계약과 검증이 필요하다.
